# Working Artifacts

Use this directory for temporary outputs and work in progress, including unfinished promotional material. Decide retention by purpose and reproducibility, not by the directory name alone.

- `artifacts/tmp/` and `artifacts/generated/` are ignored buckets for scratch and reproducible output. Do not store irreplaceable evidence or authored originals there.
- Keep shared source, useful non-reproducible evidence, and authored deliverables outside those buckets; review them deliberately before tracking.
- Move intentional promotional deliverables into `marketing/`, visual candidates into `prototype/`, and selected game media into `assets/`, preserving source and prompt links.
- Build/export/release outputs stay ephemeral. Produce them only for the authorized workflow, retain only the active candidate, and remove generated local outputs after verified publication unless retention is explicitly required.
