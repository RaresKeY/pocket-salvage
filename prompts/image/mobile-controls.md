# Mobile action icons — 2026-09-25

Requested by RaresKeY in [mobile overlay](../source/mobile-overlay.md). Generated using the built-in imagegen tool, one call per icon, then copied unchanged to `assets/ui/mobile/`. Transparent RGBA masters are 1254×1254; Godot imports at 128px with mipmaps and the overlay uses linear filtering. These are deliberately smooth UI art, separate from pixel yard sprites. No external icon pack.
