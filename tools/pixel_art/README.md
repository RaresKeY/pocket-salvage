# Pixel-Art Creation Tools

`superscale.gd` enlarges PNGs through Godot's native nearest-neighbor image operation. The shared workstation entry point is `./tools/superscale`; [the lab guide](../../labs/pixel_scaling/README.md) documents the portable Godot command and examples. Keep originals, choose a new output path, and retain the adjacent provenance record for an accepted derivative.

`make_fixture.gd` regenerates `assets/pixel_lab/calibration.png`. Run it through the shared Godot runner on this workstation. It is deterministic diagnostic-image construction, not an art-generation prompt.
