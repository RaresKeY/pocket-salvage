# Shared game-developed tools

## User design

RaresKeY requests copying project-born working tools, testing complete ports, making them reusable and updating their origins. Exact directives: [source request](../prompts/source/shared-game-tools-wave-2.md). This includes the existing audio authoring method.

## AI-inferred design

Keep the complete mathematical method in the capability-based shared library and preserve this project’s exact collection as explicit presets. Use reviewed commit/SHA-256 pins and a complete offline bundle so the original command/API continues to work. Generic callers choose their own names, notes, seeds, rates and folders, with overwrite rejection by default. The source retains its historical regeneration policy. Runtime sound selection, current masters and final hearing acceptance stay with this game.

Implementation and measured boundaries: [shared ownership spec](../specs/shared-game-dev-tools.md).
