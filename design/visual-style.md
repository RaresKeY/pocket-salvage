# Visual Direction

## User design

The user requested alignment with Jam Sync: choose and document a cohesive direction before generating images, preserve exact prompts, compare candidates, and verify selected assets in-game. No game-specific visual style has been selected.

## AI-inferred design

No palette, theme, material language, or reference set is proposed by this bootstrap. The [style example](../examples/visual-style.md) is an illustration only.

## Decisions required before generation

Record the chosen mood, palette, shapes, materials, perspective, lighting, and readability constraints, together with contributor and selection status. Identify approved references and how the direction carries into assets, UI, and game presentation.

Keep mockups and input references in [prototype/](../prototype/README.md), record exact prompts through [prompts/](../prompts/README.md), and promote selected runtime media into [assets/](../assets/README.md). Record in-game checks and remaining uncertainty. Trellis models remain experimental candidates until evaluated in the game.
