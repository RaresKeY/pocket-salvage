# Sorting and timed round

Reviewed: 2026-09-24, initial subsystem implementation (commit introducing this file).

`scripts/round/round_controller.gd` is a manually clocked Node. `configure(seconds=90, item_count=0)` resets to ready; `start()` resets all counters and consumed IDs and enters running. Caller invokes `tick(delta)` once per frame; nonpositive/nonfinite deltas are ignored. `set_paused(bool)` transitions running/paused. `accept_delivery(item_id, material, bin_material)` returns a `Delivery` enum: `IGNORED` outside running or for an already sorted ID, `WRONG` for a mismatch and `CORRECT` for a match. A match adds `CORRECT_POINTS` (100), consumes the ID and increments `correct_count` and `delivered_count`. A mismatch subtracts `WRONG_PENALTY` (25) with no floor, increments `wrong_count` only, and leaves the ID unconsumed so the same item can still be sorted. A positive total_items finishes with `all_sorted` once that many items are sorted correctly, adding `time_bonus` of `TIME_BONUS_PER_SECOND` (5) per whole remaining second; zero means no item-count finish. Remaining time reaching zero finishes with `timeout` and no bonus. `finish(reason)` is idempotent outside running/paused. `changed` follows state/counter updates; `finished(reason)` fires once per finish transition. There is no automatic processing or scene ownership.

`scripts/round/sorting_bin.gd` owns prototype caller-configurable bin geometry and an independent Area2D sensor. Configure material, local position, and size before adding to the tree (or rebuild afterward outside physics callbacks). Default size is 150×100; origin is center. Art uses the existing 8× material bin sprite displayed at configured size with linear filtering. Walls and bottom are authored rectangles on layer 1, mask 2; sensor is layer 0, mask 2. These rectangles are diagnostic geometry, not bitmap-derived or final game object design.

Each physics frame checks actual overlaps, accepting only bodies in `salvage_scrap` with boolean `held == false` and `delivered == false`. It marks delivered before emitting `delivered(body, bin_material)`, so overlapping bins cannot consume the same body twice. Rechecking allows release while already inside the sensor. Set `enabled` from the round state synchronously on `changed`; disabled sensors never mark items. `eject(body)` refuses a delivered body: it sets `eject_velocity` (x mirrored toward the nearer wall) and keeps `delivered` true until the body leaves the sensor, or `eject_timeout` (1.5 s) passes, then clears it so the body is back in play. The caller owns scoring callback, material identity, freezing/removing bodies and collision changes; use deferred physics changes in callbacks. Sensor acceptance means shape overlap, not full containment or settled motion.

`labs/sorting/lab.tscn` proves scoring, pause/restart and physical drop detection with synthetic square fixtures and three material bins. Keys 1–3 drop the next of six alternating material fixtures into a chosen bin; P pauses; R resets. Wrong drops in the lab are ejected. `tests/round_test.gd` checks correct/wrong outcomes, negative score, time bonus, duplicates, lifecycle, timeout, restart and actual Area overlap including held/disabled/release/once-only behavior, ejection release once clear and after the timeout. This headless verification does not prove hardware rendering or game balance.
