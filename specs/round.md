# Sorting and timed round

Reviewed: 2026-09-24, initial subsystem implementation (commit introducing this file).

`scripts/round/round_controller.gd` is a manually clocked Node. `configure(seconds=90, item_count=0)` resets to ready; `start()` resets all counters and consumed IDs and enters running. Caller invokes `tick(delta)` once per frame; nonpositive/nonfinite deltas are ignored. `set_paused(bool)` transitions running/paused. `accept_delivery(item_id, material, bin_material)` returns false outside running or for duplicate IDs. Matching materials add 100, mismatches subtract 25 with score clamped at zero. Every accepted delivery increments delivered_count. A positive total_items finishes once reached; zero means no item-count finish. Remaining time reaching zero finishes with `timeout`; all items gives `all_sorted`. `finish(reason)` is idempotent outside running/paused. `changed` follows state/counter updates; `finished(reason)` fires once per finish transition. There is no automatic processing or scene ownership.

`scripts/round/sorting_bin.gd` owns prototype caller-configurable bin geometry and an independent Area2D sensor. Configure material, local position, and size before adding to the tree (or rebuild afterward outside physics callbacks). Default size is 150×100; origin is center. Art uses the existing 8× material bin sprite displayed at configured size with linear filtering. Walls and bottom are authored rectangles on layer 1, mask 2; sensor is layer 0, mask 2. These rectangles are diagnostic geometry, not bitmap-derived or final game object design.

Each physics frame checks actual overlaps, accepting only bodies in `salvage_scrap` with boolean `held == false` and `delivered == false`. It marks delivered before emitting `delivered(body, bin_material)`, so overlapping bins cannot consume the same body twice. Rechecking allows release while already inside the sensor. Set `enabled` from the round state synchronously on `changed`; disabled sensors never mark items. The caller owns scoring callback, material identity, freezing/removing bodies and collision changes; use deferred physics changes in callbacks. Sensor acceptance means shape overlap, not full containment or settled motion.

`labs/sorting/lab.tscn` proves scoring, pause/restart and physical drop detection with synthetic square fixtures and three material bins. Keys 1–3 drop the next of six alternating material fixtures into a chosen bin; P pauses; R resets. `tests/round_test.gd` checks score/clamp, duplicates, lifecycle, timeout, restart and actual Area overlap including held/disabled/release/once-only behavior. This headless verification does not prove hardware rendering or game balance.
