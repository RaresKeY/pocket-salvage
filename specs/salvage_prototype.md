# Playable subsystem integration

Reviewed: 2026-09-24, implementation introducing the combined playable lab.

User direction: delegate independent subsystem work to worktrees, commit/push progress, test the result, and report readiness. This follows the subsystem/lab workflow and previously identified missing crane, sorting, round, UI and level work. Concrete parameters below are prototype decisions; reusable component contracts remain separately documented.

`labs/salvage/lab.tscn` composes crane suspension, round/bin, HUD and level layout modules without replacing the static yard preview. `scripts/scene/yard_preview.gd` adds Play prototype; F2 returns. Each subsystem retains its own lab and verification. The full game is not yet declared finished.

The fixture has six caller-configured RigidBody2D items, three bins and a 120-second round. Materials are copper/rubber/steel; the arcade pickup accepts any material within 62 world units of its top attachment point, with a wall ray check, and holds at most one item. Solids layer1, scrap layer2, magnet layer4. Payloads use independent rectangle shapes and stored 8× art with uniform linear-filtered visual scaling. Bin artwork remains axis-aligned; masks are not integrated into this prototype.

A/D or left/right moves the trolley at220 units/s within x80–1120; W/S or up/down changes cable length at130 units/s within50–335. The magnet is a rigid body with a top cable pivot, bottom load mount, inertia and a ±35° tilt cap. Native damping replaces the earlier per-frame horizontal velocity cancellation; cable tension and load reactions drive its movement. Space toggles pickup/release. The attached body remains dynamic and exchanges equal/opposite spring forces with the magnet. The cable is drawn behind both magnet and hoist. No load-force feedback into the trolley, terrain-wrap polygons, or real-world magnetic material simulation is configured. These are prototype boundaries, not new guarantees for the rope subsystem.

Round state starts ready; Start/Enter begins, P/Escape toggles pause, R rebuilds all transient world objects and restarts. Focus loss pauses. Pausing disables world simulation while retaining timer, object state and attachment; resuming restores it. Presentation uses more of the contributed art: the magnet shows frame 01 while off, plays the 02 to 06 charge frames when switched on and then loops 05/06; `scripts/fx/burst_2d.gd` plays one-shot six-frame sparks at the grip point on pickup and at a correctly sorted item, and dust where scrap lands falling faster than 160 units/s (`payload.gd` emits `landed`). Floating +100 / −25 numbers rise from each sorted or refused item, heavy scrap (mass 1.5 and up) shakes the stage by up to 5 units when it lands, and the timer turns red and pulses for the last 10 seconds. Delivery sensors accept only released items. A correct item scores +100 and retires deferred. A wrong item scores −25 (score may go negative) and the bin lobs it back out to 60 units in front of the leftmost bin, inside crane reach, so it must still be sorted. All six sorted correctly ends the round with a time bonus of 5 per remaining second; time zero ends it without one. Either end releases the load, disables bin acceptance and exposes results/replay. HUD receives snapshots, never owns score/time state.

The world is rendered into a native-resolution SubViewport between the HUD bands, fitting1200×480 world units with preserved aspect ratio. All layout placements are supplied by the configurable layout module. The prototype uses variant0; the independent level lab demonstrates both variants.

Verification: the integration test drives all six pickups, lifts, transports and deliveries through physics (no payload teleporting), sends the first item to a wrong bin and sees it thrown back out and later sorted, scores 575 plus the time bonus, verifies pause while carrying, early completion, clean restart, timeout release and disabled end-state sensors. The full check suite retains independent module and prior lab checks. Hardware screenshots and interaction captures are separate from headless behavior tests. Tests establish deterministic playability; human playtesting still decides whether the handling is fun.

This is functional/visual evidence, not a performance benchmark or human fun assessment.

The v0.1.0 standalone exports start this scene directly and hide/disable F2 preview navigation via the `standalone` feature. Development scene navigation remains available. The HUD shows the project version in its lower-right corner; the world reserves 100px above and 121px below. Spawn/restart and pause transitions synchronize interpolation history without changing simulation state.
