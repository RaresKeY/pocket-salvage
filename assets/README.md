# Game Media

Selected media used by the game belongs here. Preserve source, license/provenance, and prompt lineage when applicable. Choose a coherent direction in `design/` and evaluate candidate media in-game before treating it as accepted.

Mockups and input references belong in `prototype/`; promotional deliverables belong in `marketing/`. Trellis-generated models remain experimental candidates until their in-game quality is checked. No game media is present yet.
