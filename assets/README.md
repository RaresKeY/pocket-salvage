# Game Media

Selected media used by the game belongs here. Preserve source, license/provenance, and prompt lineage when applicable. Choose a coherent direction in `design/` and evaluate candidate media in-game before treating it as accepted.

Mockups and input references belong in `prototype/`; promotional deliverables belong in `marketing/`. Trellis-generated models remain experimental candidates until their in-game quality is checked. [pixel_lab/](pixel_lab/README.md) contains diagnostic media. `bitwright/` contains Dale Mooney's contributed Pocket Salvage scrapyard sprites (`f315834`) and separate masks (`3cec96b`). They are arranged in the [main scene preview](../specs/scene_preview.md); their collision/mask integration and generation provenance remain to be documented. They are preserved as contributed, with lossless Godot import settings and no mipmaps. The night scenery, critters and smoke added on 2026-09-25 come from the same Bitwright `scrapyard` set (matched to the magnet anchor) via `tools/pixel_art/import_bitwright.py`. `audio/` holds the round's sound effects, generated by `tools/audio/make_sfx.py`.

Read [the art specs module](../specs/art/_readme.md) when importing any art. Classify pixel sprites, smooth artwork, fonts/vector UI, and 3D materials before selecting their sampling settings. Add collaborator PNGs in an appropriately named folder here and use **Refresh art** in the lab to compare them.
