# Local Instruction Examples

[random-game.md](random-game.md) is the portable repository example. The shared rules now live in the tracked root [AGENTS.md](../AGENTS.md), which `CLAUDE.md` imports; keep your environment's engine, container, hardware, and resource constraints in untracked notes.

Both local filenames are always ignored. This directory is tracked so contributors can share repository guidance without imposing one machine's configuration on everyone.
