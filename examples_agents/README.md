# Local Instruction Examples

[random-game.md](random-game.md) is the portable repository example. Adapt its shared contributor rules into ignored local `AGENTS.md` and `CLAUDE.md`; keep your environment’s engine, container, hardware, and resource constraints there. See [migration notes](../docs/collaboration.md#repository-migration).

Both local filenames are always ignored. This directory is tracked so contributors can share repository guidance without imposing one machine's configuration on everyone.
