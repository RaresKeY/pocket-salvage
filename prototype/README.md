# Visual Prototypes

Keep image-generation mockups and their input references or game screenshots here. For an actual experiment, use `prototype/<experiment>/references/` and `prototype/<experiment>/candidates/`, with a short comparison record identifying candidate files, exact prompt records, selection status, and unresolved differences.

Choose the [visual direction](../design/visual-style.md) before generation. Preserve prompt lineage in [prompts/](../prompts/README.md); record the selected direction in `design/`. A mockup is a visual target, not proof of runtime behavior or an automatically accepted game asset.

Trellis 3D generation is experimental. Preserve the source and resolved settings of generated candidates, evaluate topology, materials, silhouette, and readability in-game, and promote a candidate into [assets/](../assets/README.md) only after selection. No models or images are present yet.
