# Visual-Style Record Example

AI-authored illustration adapted from Jam Sync's visual-style example at `d2c801a`. This is not approved Pocket Salvage design, and the prompt below has not been sent to a generation tool.

| Aspect | Illustrative direction |
|---|---|
| Mood | A cheerful repair kiosk with the clarity of a handcrafted toy. |
| Palette | Midnight ink, cream, apricot, mint, and coral. |
| Shapes and materials | Rounded chunky forms, cut-paper gouache, rubber, and powder-coated metal. |
| View and lighting | Frontal or mild three-quarter views, thick outlines, soft short shadows. |
| Readability | Clear silhouettes at gameplay size, restrained texture, and no tiny lettering. |
| Application | Carry the same choices into assets, UI, and feedback; preserve artwork proportions. |

**Illustrative prompt, not a generation record:**

> Create a friendly repair-kiosk battery icon with a rounded cream body, midnight outline, and mint charge indicator. Use cut-paper gouache, restrained texture, a transparent background, and a readable silhouette without lettering.

For real work, record explicit user direction separately from AI proposals. Save each exact prompt and its references/outputs, compare candidates in `prototype/`, record selection in `design/`, promote selected media into `assets/`, and verify consistency and readability in-game.
